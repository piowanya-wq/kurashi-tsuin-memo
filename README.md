# くらしと通院メモ

作成日: 2026-07-21
作成担当: Codex
最終更新日: 2026-07-21 (Codex)

**通院の時に、前回の診察から今日までの生活や状況を、医師などへ自分の言葉で報告するための生活記録アプリ**です。

## 使い方

アプリ右上の **使い方** を押すと、各ボタンで何が起こるかを読めます。

1. **今日を記録する** — 💤寝た・🌞起きた、🍚食事、今日したこと、日記を残す。必要な薬などは自分で作る項目として追加できる。
2. **通院時に見る・見せるメモ** — 前回の診察から今日までなど、見たい期間と項目を選んで画面に出す。コピーもできる。
3. **項目を整える** — 記録する項目を隠す／表示する。例「朝の薬（ミヤBM）」のような自分用の項目も作れ、通院メモに表示するかも選べる。薬が変わった時は、新しい項目を追加して切り替える。
4. **JSONにする** — 設定から全記録を、通院メモからは選んだ期間を、端末のダウンロードへ保存する。機種変更やブラウザ変更の前は全記録を保存し、移した先で「JSONを読み込む」を押す。
5. **ホーム画面に追加** — スマホのブラウザのメニューから「ホーム画面に追加」を選ぶと、アプリのように開ける。

## 自分で作る項目について

- 薬が変わった時は、古い項目の名前を変えず、例「朝の薬（新しい名前）」のように新しい項目を追加する。過去に何を記録したかが変わらない。
- 項目を削除すると、いま使う一覧と通院メモの選択肢から外れる。過去の記録データは端末内とJSONに残る。
- 以前の項目をまた使いたくなったら、同じ名前で追加し直せる。

## 公開後に更新する人へ

このアプリは、使う人それぞれの端末内に記録を残す。公開後の更新では、すでに書かれた記録を壊したり消したりしない。

- 初期項目（外出・仕事・入浴・体調不良など）の保存キーを削除・改名しない。すでに使っている人の過去記録が表示されなくなる可能性がある。
- 項目を増やすのはよい。不要になった項目は、過去の記録を読める状態のまま画面で隠す。
- データベース名、テーブル名、日付キー、既存の保存項目を変える時は、以前の記録を安全に移す処理とJSONの読み込み確認を必ず用意する。
- 変更前にJSONを書き出し、更新後に読み込めることを確認する。

この約束は、利用者の記録を守るためのもの。

## 大切なこと

- 記録がない日は「していない」という意味にはならない。
- 項目を隠しても、過去の記録は消えない。
- JSONには個人情報を含むことがある。メール添付や共有をする相手は、自分で選ぶ。
- 機種変更やブラウザのデータ削除に備えて、ときどき全記録をJSONに保存する。
