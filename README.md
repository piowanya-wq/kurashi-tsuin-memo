# くらしと通院メモ

作成日: 2026-07-21
作成担当: Codex
最終更新日: 2026-07-21 (Codex)

生活の記録と、通院で伝えたいことを、端末の中だけに残すPWA。評価や診断をしない。記録はサーバーへ送られない。

## できること

- 今日の睡眠・食事・薬・活動・メモを記録
- 記録する項目を設定で増減
- 通院メモは期間（7〜90日／すべて）と表示項目を選択
- 通院メモをコピー、または選んだ期間だけJSONで端末へ保存
- すべての記録をJSONで避難・読み込み

JSONは端末のダウンロードに保存される。個人情報を含むことがあるため、送る相手は自分で選ぶ。
